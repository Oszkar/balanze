# Design record: surface consistency

Balanze shows the same usage on four surfaces - the tray icon, the popover, the CLI, and the Claude Code statusline. They need one shared color language so a color means the same thing everywhere: **green / yellow / orange / red at 50 / 75 / 90**, always explained by a number you can see next to it.
